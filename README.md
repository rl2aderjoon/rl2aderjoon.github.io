# rl2aderjoon.github.io

장효준의 개인 사이트입니다. [공개 사이트](https://rl2aderjoon.github.io/)

- `index.html`: AI 채팅 서비스처럼 입력창 하나에서 시작하는 블로그. 개발 기록·포트폴리오·사진·독후감을 담습니다. 작업 중인 시안이며, 스타일과 스크립트가 모두 들어 있습니다.
- `2026/index.html`: 한 장짜리 2026 포트폴리오 ([/2026/](https://rl2aderjoon.github.io/2026/))
- `assets/media/`: 프로젝트 화면, 삐용 주행 영상, 수상 사진
- `assets/blog/`: 블로그의 사진과 책 표지
- `assets/fonts/`: LINE Seed KR, Pretendard (둘 다 SIL OFL, 라이선스 동봉)
- `_writing/`: 글 초안. 공개하지 않으며 `.gitignore`로 뺍니다.
- `.nojekyll`: HTML을 변환 없이 그대로 배포합니다.

GitHub Pages가 `main` 브랜치 루트에서 배포합니다.

## 첫 화면(`index.html`)의 기준

**흐름**
1. 표식과 시간대 인사("좋은 오후예요"), 입력창, 바로가기 단추가 1초쯤 보입니다.
2. 화면이 입력창으로 줌인하고, 나머지는 사라집니다(`zoomIn()`).
3. 확대된 입력창에 "장효준의 블로그를 보여줘"가 한 글자씩 쳐집니다.
4. 보내면 한 번 더 다가가며 사라지고, 사이드바와 대화 화면으로 넘어갑니다.

"처음부터 다시"는 이 흐름을 다시 틀고, "건너뛰기"는 바로 대화 화면으로 갑니다.

**색**: 흑백만 씁니다. 2026 포트폴리오와 같은 회색 단계이고, 네 갈래(개발 기록·포트폴리오·사진·독후감)도 색 대신 회색의 진하기로 나눕니다. 밤 모드도 같은 규칙입니다.

**글꼴**: LY 기술 블로그와 같은 LINE Seed입니다. 한글은 저장소에 둔 LINE Seed KR, 영문·숫자는 Google Fonts의 LINE Seed JP를 씁니다. 파일을 직접 열면(`file://`) 한글 글꼴이 안 불러와지므로 서버로 띄워 확인합니다.

```bash
python -m http.server 8765
```

**컴포넌트**
- 흰 바탕 위 회색 묶음 판. 고른 항목만 흰 카드로 떠오릅니다(사이드바 `01 개발 기록` 목록).
- 입력창·통계·갈래 카드·대표 글은 크게 둥근 흰 카드에 넓고 옅은 그림자를 씁니다.
- 카드 안의 줄(통계 칸, 글 목록)은 회색으로 채운 둥근 줄입니다.
- 단추는 두 가지입니다. 진한 알약(보내기, 읽기)과 흰 테두리 알약(칩, 모두 보기, 바로가기).
