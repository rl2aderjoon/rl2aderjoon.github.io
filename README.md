# rl2aderjoon.github.io

장효준의 개인 사이트입니다. [공개 사이트](https://rl2aderjoon.github.io/)

- `index.html`: AI 채팅 서비스처럼 입력창 하나에서 시작하고, 보내면 달마다 묶은 잡지(월간 호)의 표지와 차례가 뜹니다. 프로젝트·글·서평·사진을 담습니다. 작업 중이며, 스타일과 스크립트가 모두 들어 있습니다.
- `2026/index.html`: 한 장짜리 2026 포트폴리오 ([/2026/](https://rl2aderjoon.github.io/2026/))
- `assets/media/`: 프로젝트 화면, 삐용 주행 영상, 수상 사진
- `assets/blog/`: 블로그의 사진과 책 표지
- `assets/fonts/`: LINE Seed KR, Pretendard (둘 다 SIL OFL, 라이선스 동봉)
- `_writing/`: 글 초안. 공개하지 않으며 `.gitignore`로 뺍니다.
- `.nojekyll`: HTML을 변환 없이 그대로 배포합니다.

GitHub Pages가 `main` 브랜치 루트에서 배포합니다.

## 첫 화면(`index.html`)의 기준

**흐름**
1. 표식과 시간대 인사("좋은 오후예요"), 입력창, 바로가기 단추가 1초쯤 보입니다.
2. 화면이 입력창으로 줌인하고, 나머지는 사라집니다(`zoomIn()`).
3. 확대된 입력창에 "장효준의 블로그를 보여줘"가 한 글자씩 쳐집니다.
4. 보내면 한 번 더 다가가며 사라지고, 이번 호의 표지와 차례가 한 화면에 뜹니다.

시작 화면의 바로가기(프로젝트·글·서평·사진)를 누르면 인트로를 건너뛰고 그 탭이 열린 차례로 갑니다. 차례 아래의 "인트로 다시 보기"는 이 흐름을 다시 틉니다.

**월간 호 구조**
- 첫 화면은 왼쪽 표지(직접 찍은 사진, 호 이름, 이번 호 제목)와 오른쪽 차례입니다. 컴퓨터에서는 스크롤 없이 한 화면에 들어옵니다.
- 차례 칸 맨 위의 탭(이번 호·프로젝트·글·서평·사진)이 분류 메뉴입니다. 표지는 그대로 두고 목록만 바뀝니다. 프로젝트는 호와 상관없이 늘 같은 네 개(삐용, 가볼래, 로보터블, axMap)입니다.
- 글을 열면 첫 장(제목·요약·대표 그림이 한 화면)이 나오고, 아래로 한 단 본문이 이어집니다. 긴 글에는 여러 단이나 가로 넘김을 쓰지 않습니다.
- 글 화면 위쪽 머리글("2026년 11월호 · 글 · 03 / 05")은 늘 같은 자리에 있습니다. 호 이름을 누르면 그 호의 차례로, 분류 이름을 누르면 그 분류 전체 목록으로 갑니다.
- 앞뒤 넘김과 글 끝의 "다음"은 들어온 목록(이번 호 또는 분류)의 순서를 따릅니다.
- 이번 호에 실을 글은 `index.html`의 `ISSUE`(글 id 순서), `ISSUE_T`(차례에 쓸 제목), `ISSUE_NAME`(호 이름)과 `tpl-mag` 템플릿의 차례 목록에서 정합니다.

**색**: 흑백만 씁니다. 2026 포트폴리오와 같은 회색 단계입니다. 표지 사진만 색이 있습니다. 밤 모드도 같은 규칙입니다.

**글꼴**: LY 기술 블로그와 같은 LINE Seed입니다. 한글은 저장소에 둔 LINE Seed KR, 영문·숫자는 Google Fonts의 LINE Seed JP를 씁니다. 파일을 직접 열면(`file://`) 한글 글꼴이 안 불러와지므로 서버로 띄워 확인합니다.

```bash
python -m http.server 8765
```

**컴포넌트**
- 흰 바탕 위 회색 묶음 판. 고른 항목만 흰 카드로 떠오릅니다(사이드바 `01 개발 기록` 목록).
- 입력창·통계·갈래 카드·대표 글은 크게 둥근 흰 카드에 넓고 옅은 그림자를 씁니다.
- 카드 안의 줄(통계 칸, 글 목록)은 회색으로 채운 둥근 줄입니다.
- 단추는 두 가지입니다. 진한 알약(보내기, 읽기)과 흰 테두리 알약(칩, 모두 보기, 바로가기).
