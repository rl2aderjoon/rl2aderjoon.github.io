지도는 어떻게 나뉘어 있나요?

서울은 8개 권역, 부산은 8개 권역으로 구·군을 묶었어요. 그 외 지역은 시·군·구, 전국 지도는 17개 시도에 번호를 붙였어요. 번호는 공유를 위한 구분이며 공식 생활권이나 선호도 순위가 아닙니다. 지도는 2023년 7월 배포 경계를 바탕으로 단순화했으며, 이후 행정구역 변경은 반영되지 않을 수 있습니다.

저장과 공유는 자유롭게 해도 되나요?

개인 SNS와 채팅방에서 자유롭게 저장하고 표시해 공유하세요. PNG는 1600 × 1600 크기예요. X 앱 안에서 저장이 어려우면 브라우저로 열어 저장해 보세요. 경계 출처는 국가공간정보포털, 가공은 KnellBalm/kr-admin-geojson입니다.

다운로드 횟수는 어떻게 집계되나요?

PNG 받기는 GitHub 첨부파일로 연결돼요. 표시된 횟수는 GitHub가 집계한 파일 다운로드 수로 반복 다운로드가 포함되며, 고유 사용자 수·저장 완료·선호 투표 수를 뜻하지 않습니다. 수치는 최대 5분간 캐시되며 GitHub 반영이 지연될 수 있어요. 조회할 수 없으면 —로 표시합니다. 별도의 방문 분석 도구는 사용하지 않아요.
